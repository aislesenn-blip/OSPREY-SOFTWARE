# OSPREY OS - User Manual

## Overview
OSPREY is the unified operating system for high-end safari operations. It connects Arusha HQ with bush camps in real-time.

## 1. Central Command (Inventory Manager)
### Dashboard
- Navigate to **Inventory** to view the Master Item Database.
- Monitor "Low Stock" alerts.

### Receiving Goods (Blind Receiving)
- Click **Receive Goods**.
- Select the item from the dropdown.
- **CRITICAL:** You must physically count the items. The system does not show you the expected quantity.
- Enter the physical count. Any variance will be flagged to Finance automatically.

## 2. Camp Operations (Camp Manager)
### Live Manifest
- Navigate to **Camp Ops**.
- View all in-house guests.
- **Allergy Alerts:** Look for the RED shield icon next to guest names. Ensure the kitchen is notified immediately.

### Maintenance
- If a room has an issue, click **Report Issue**.
- This will mark the room as "Maintenance" and prevent new bookings for that room until resolved.

## 3. Fleet & Logistics (Driver/Mechanic)
### Fleet Dashboard
- Navigate to **Fleet**.
- Check vehicle status. **RED** vehicles are BLOCKED due to overdue service. Do not take them on game drives.

### Dispensing Fuel
- Click **Dispense Fuel**.
- **Requirement:** You MUST have a valid Trip ID.
- Enter the Liters and Current Odometer.
- The system checks if the consumption matches the route.

## 4. HR & Staff (HR Manager)
### Rota & Rations
- Navigate to **HR & Staff**.
- The "Ration Count" is calculated automatically based on staff marked "Active" in the system.
- Use this number to issue food from the store.

## 5. Security (Gate Guard)
### Issuing a Gate Pass
- Navigate to **Security**.
- Select the Vehicle.
- Enter Driver Name and Load Description.
- Click **Generate Gate Pass**.
- A QR Code will appear. This authorizes the vehicle to leave.

## 6. Finance (Accountant)
### General Ledger
- Navigate to **Finance**.
- View the real-time General Ledger.
- All inventory receipts, fuel logs, and maintenance costs are captured here as double-entry records.
